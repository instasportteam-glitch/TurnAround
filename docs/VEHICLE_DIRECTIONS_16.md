Vehicle orientation v4

Generated with built-in imagegen, using each earlier eight-view sheet as visual reference. Source PNGs remain unmodified. Project files: assets/images/bags-directions-16.png, assets/images/fuel-directions-16.png, assets/images/clean-directions-16.png, assets/images/cater-directions-16.png, assets/images/tug-directions-16.png.

Each source atlas contains 16 frames (4x4). Generated angles are not perfectly uniform and some views are similar; vehicle_heading.dart stores approximate observed screen-space axes rather than assuming ideal 22.5 degree spacing. Renderer chooses the closest view and applies a residual angular correction. The old eight-view crossfade is removed. Cells are rendered square, avoiding the prior vertical compression which distorted the heading. Travel orientation uses actual per-step displacement. Departure waits until steering error is below 0.045 radians.
